- GPIO_driver - 커널 모듈로 GPIO LED를 제어하는 문자 디바이스 드라이버를 구현하고, 사용자 프로그램을 통해 LED를 제어하는 임베디드 리눅스 프로젝트  
- kernelModule - 모듈 로드·언로드 시 커널 로그를 출력하는 기본 리눅스 커널 모듈 실습 코드  
- sevenSegment_driver - 7세그먼트 제어를 위한 리눅스 문자 디바이스 드라이버를 구현하고, 사용자 프로그램을 통해 숫자·점·전체 소등을 제어하는 프로젝트  
- sharkGame - 주사위 기반 보드에서 플레이어 이동·코인 획득·상어 추격/포획 로직을 구현한 콘솔 게임 프로그램  
  
- crash.c - 잘못된 포인터 접근으로 메모리 오류(세그멘테이션 폴트)를 확인하는 실습 코드  
- turn7segment.c - mmap()을 통해 GPIO 레지스터를 직접 제어하여 7세그먼트 핀을 설정하는 코드  
- turnled.c - 스위치 입력을 감지해 LED를 제어하고 누른 시간을 측정하는 GPIO 제어 코드
