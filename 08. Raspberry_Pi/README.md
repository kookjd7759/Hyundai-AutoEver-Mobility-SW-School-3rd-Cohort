- GPIO_driver - 라즈베리파이에서 메모리 매핑 방식으로 GPIO 레지스터를 직접 제어하여 핀 입출력 및 LED 동작을 구현하는 GPIO 드라이버 실습 코드
- kernelModule - 리눅스 커널 모듈(LKM)을 작성하여 모듈 로드 및 제거 시 커널 로그 메시지를 출력하는 기본 커널 모듈 실습 코드  
- sevenSegment_driver - 라즈베리파이 GPIO 제어를 통해 7-Segment 디스플레이의 숫자를 출력하도록 구현한 드라이버 및 제어 실습 코드
- sharkGame - 라즈베리파이에서 7-Segment와 LED를 이용해 상어(Shark) 게임 로직과 사용자 입력 처리를 구현한 임베디드 게임 실습 코드
<br>  

- crash.c - 라즈베리파이에서 예외 상황 또는 시스템 충돌 동작을 실험하기 위한 테스트용 코드
- turn7segment.c - GPIO 제어를 통해 7-Segment 디스플레이의 숫자를 순차적으로 표시하는 실습 코드
- turnled.c - 라즈베리파이 GPIO를 이용해 LED를 켜고 끄며 기본 디지털 출력 제어를 학습하는 실습 코드
